# Visual assets

`healpot-logo.png` is the original transparent HealPot healing-potion logo, reused unchanged with the project owner's permission. It was generated for the owner's project and is included under this repository's MIT license.

Fonts are hosted locally so rendering does not require requests to a third-party font service:

- Instrument Serif, from https://github.com/google/fonts/tree/main/ofl/instrumentserif
- DM Mono, from https://github.com/google/fonts/tree/main/ofl/dmmono

Their respective SIL Open Font License files are included in `../fonts/`. Font licensing remains OFL, independently of the application's MIT license.

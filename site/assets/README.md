# Visual assets

`healpot-logo.png` is the original HealPot logo, generated for the owner's project and reused unchanged with their permission under this repository's MIT license.

The site loads these fonts locally without a third-party font service:

- [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif)
- [DM Mono](https://github.com/google/fonts/tree/main/ofl/dmmono)

The fonts use the SIL Open Font License. Their license files are in `../fonts/` and remain separate from the application's MIT license.
